================================================================================
1) PIPELINE AUDIO LOGICIEL - Wake word, VAD, backend, reponse
================================================================================

Professional academic infographic, clean flat technical style, white background,
French labels, for a final-year engineering report about an embedded companion
robot named KODA.

Title: "Pipeline audio logiciel du Raspberry Pi"

Left-to-right flow with 8 blocks:
(1) Utilisateur parle
(2) ReSpeaker 4-Mic USB
(3) Flux PCM local
(4) Vosk Wake Word local
(5) VAD avec sox - capture jusqu'au silence
(6) Backend FastAPI - STT, n8n, TTS
(7) ActionResult JSON
(8) Sortie audio Bluetooth / jack

Add a small note under Vosk: "Aucun appel cloud avant le mot de reveil".
Use blue, green and gray accents, thin arrows, no logos, no watermark, readable
on A4 landscape.

Negative prompt: photorealistic robot, dark background, complex equations,
English-only labels, tiny unreadable text, brand logos.

================================================================================
2) RASPBERRY PI COMME CORPS OPERATIONNEL DE KODA
================================================================================

Clean educational infographic, white background, French labels, soft blue and
green palette. Show a central Raspberry Pi board icon labeled "Logiciel
Raspberry Pi" connected to five body functions around it:
"Oreille - Wake word + VAD", "Orientation - DOA", "Voix - TTS", "Visage -
Nextion", "Corps - Arduino USB". On the right, show "Backend FastAPI + n8n"
as the remote brain/memory.

The visual message: Raspberry Pi transforms decisions from backend/n8n into
physical behavior of the robot. Use simple vector-like shapes, high readability,
not a marketing hero, not photorealistic. A4 landscape, academic report style.

Negative prompt: cyberpunk, neon dark theme, humanoid face close-up, cluttered
wires, unreadable text, logos, watermark.

================================================================================
3) CYCLE ETATS PASSIF / ACTIF / SOMMEIL
================================================================================

Professional state-cycle diagram for an embedded robot software chapter, French
labels, white background, clean rounded nodes, blue-gray palette.

Show the lifecycle:
"BOOT" -> "DIAGNOSTIC MATERIEL" -> "PRET" -> "PASSIF"
From PASSIF: "mot reveil" -> "ORIENTATION DOA" -> "SALUTATION" -> "ECOUTE"
-> "TRAITEMENT BACKEND" -> branches:
"REPONSE VOCALE", "MOUVEMENT", "MUSIQUE", "SOMMEIL", "ERREUR".
Then return to "PASSIF" after response or silence.

Use clear arrows, no decorative background, no icons that distract. Must be
readable in a printed PFE report.

Negative prompt: game UI, dark sci-fi, too many colors, tiny text, watermark.
